# Indian Standards (IS) referenced in this repo

This is a catalogue, not a mirror. The Acts, Rules, Regulations and gazette
notifications in `sources/` routinely point to a specific **Indian
Standard** (an "IS" number) rather than spelling out a technical
requirement themselves — e.g. the Hallmarking Regulations don't define
what "22-karat gold" means numerically, they just say *"conforming to
IS 1417"*. Those IS documents are BIS's actual technical specifications,
sold individually (with a narrow free/"Indigenous Standards" exception)
through BIS's official e-Sale portal, [standardsbis.bsbedge.com](https://standardsbis.bsbedge.com/),
and DRM-locked to a required viewer plugin on download. That's a
fundamentally different distribution model from the public-domain Acts
and notifications mirrored elsewhere in this repo — so rather than
attempting to mirror them, this page just lists which ones the repo's
primary sources actually cite, with enough context to look each one up
yourself.

**37 distinct IS numbers found**, cited by 5 of the 36 entries. Every row
below is traceable to an exact line in a mirrored, already-public
source — click through if you want to verify a citation yourself rather
than take this table's word for it.

## How this was compiled

Every citation above was found by pattern-matching `IS ####` (and its
`IS/ISO`, `IS:####`, `IS ####:YYYY`, `IS #### (Part N)` variants) across
every mirrored source text in `sources/**/*.md` — the PDF-extraction
transcriptions described in [`docs/00-overview.md`](00-overview.md) and
linked from each entry's Primary source section — then reading the
surrounding context by hand to confirm each match was a real citation and
attach a title. This is necessarily a lower bound: a standard referenced
only in a document that isn't a native-text/OCR'd PDF in this repo (an
HTML-only source, or a PDF whose OCR missed it) won't show up here. It's
also not automatically regenerated — a source doc changing later doesn't
retroactively update this page — so treat it as a snapshot from
2026-09-24, not a live index.

**Looking up a standard**: search by number on
[standardsbis.bsbedge.com](https://standardsbis.bsbedge.com/), BIS's
official e-Sale portal — not mirrored here, per the note at the top of
this page.
